# 콘텐츠 미확정 항목과 임시 구현 경계

이 문서는 갤러리·컷씬·업적·엔딩을 활성화하면서도 승인되지 않은 문구를 확정본처럼
취급하지 않기 위한 기준이다. 최신 10차 회의, 시스템 기획서 v3.5, UI 매뉴얼,
스토리 초안과 현재 모델 사건을 비교했다.

## 현재 적용한 확정 사항

- 업적 6개의 한국어·영어 이름과 순서는 UI 매뉴얼을 그대로 사용한다.
- 로라의 일기 7개와 개발자의 일기 3개는 문서 순서를 재정렬하지 않는다.
- 결과 내부 ID와 표시명을 분리한다.
  - `true` → `완벽주의자`
  - `hollow` → `학살자`
  - `special`, `failure` → `happily ever after..?`
  - 내부 ID는 판정·저장 키로만 사용하고 갤러리와 결과 화면에는 노출하지 않는다.
- 실패 결과에는 엔딩 컷씬을 자동 재생하지 않는다.
- 오프닝은 첫 런에서 한 번 자동 재생하고, 완료 또는 스킵 뒤 갤러리에서 재생할 수 있다.
- 층 전환은 모델의 `floor-transition` 사건에만 반응하며 바닥 붕괴, 암전, 지하 진입
  기능 카드를 표시한다.
- 점수와 턴별 전투 기록 화면은 표시하지 않는다. v2 저장 호환용 `bestScore` 값은 읽기만
  유지하고 새 결과로 갱신하지 않는다.

## 확정 업적 조건

업적 설명과 해금 조건은 전달받은 확정안을 사용한다. 정적 데이터의
`conditionStatus: confirmed`와 `descriptionStatus: confirmed`가 이 상태를 표시한다.
`처음` 조건은 별도 횟수 카운터를 만들지 않고 기존 메타의 업적 ID 멱등 해금으로 보장한다.

| 내부 ID | 표시명 | 확정 사건 조건 |
| --- | --- | --- |
| `steve-pickaxe` | 스티브..? | `diamond-pickaxe` 보유 상태로 실제 벽 칸을 통과한 `wall-traversed` |
| `legend-of-lora` | 로라의 전설 | `ocarina`를 획득한 `item-picked` |
| `just-the-beginning` | 이건 시작에 불과해 | `battle-finished.defeatedBy === 'lora'` |
| `another-random-player` | 그녀를 스쳐가는 또 한 명의 플레이어 | 성공한 `battle-finished` |
| `you-are-my-sunshine` | 너는 나의 빛이야 | `battle-finished`의 `endingId === true` |
| `peekaboo` | 깜짝 놀랐지? | `floor-transition.floorIndex === 1` |

갤러리에는 각 업적의 확정 해금 조건 문구를 설명으로 표시한다.

## 임시 컷씬 트리거

현재 전투 모델은 컷씬 ID를 직접 해금하지 않는다. 표시 계층의 독립 트리거 라우터가 아래
실제 사건만 컷씬으로 변환한다.

| 컷씬 ID | 현재 트리거 | 근거와 남은 질문 |
| --- | --- | --- |
| `opening` | `openingWatched`가 false인 새 런 | 첫 게임 시작 시 출력한다는 시스템 기획 |
| `teddy` | `old-teddy` 사용 | 현재 컷씬 제목·대사와 아이템 의미가 일치 |
| `item-synergy` | 같은 런에서 `mirror`와 `eyeliner` 모두 사용 | 현재 카드가 거울과 기억의 결합을 언급하나 최종 조건 미확정 |
| `extra-interaction` | `memory-photo` 사용 | 현재 카드 제목과 대사가 사진을 명시 |
| `basement-transition` | `floor-transition` | Turn 15의 필수 바닥 붕괴·암전·지하 진입 흐름 |
| `true`, `special`, `hollow` | 같은 ID의 `battle-finished` | 현재 모델 엔딩 ID를 보존 |

스토리 초안은 거울, 아이라인, 낡은 곰인형, 오르골 각각의 짧은 컷씬을 제안하지만 현재
레지스트리에는 오르골 전용 확정 카드가 없다. 새 대사를 창작하지 않고 보류한다.

## 일기 해금 정책

스토리 초안은 탐험 중 일기를 발견한다고 설명하지만 현재 9×8 두 맵에는 일기 오브젝트나
획득 사건이 없다. 임의 타일·아이템을 추가하지 않고 확정 일기 문구를 갤러리에서 처음부터
열람 가능하게 두었다. 향후 일기 획득 사건이 확정되면 메타에 안정된 일기 ID를 추가하고
이 정책을 교체해야 한다.

## 후속 승인 필요

- `special` 엔딩 유지 여부, 표시명과 최종 대사
- `failure` 결과의 최종 표시명
- 거울·아이라인·오르골 개별 컷씬 카드와 정확한 재생 시점
- 일기 조각의 맵 위치, 획득 순서와 해금 조건
- 바닥 붕괴 카드의 최종 연출 문구와 프레임 구성
- 점수 산식과 점수 기능을 완전히 제거할지, 향후 다시 승인할지 여부
