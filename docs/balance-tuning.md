# 11턴 보수 밸런스 튜닝 기록

## 상태와 판정 범위

2026-08-28 기준으로 10턴의 결정론 시뮬레이션 하네스는 준비되어 있지만,
사용자의 별도 테스트 일시 중단 지시에 따라 기준선 시뮬레이션과 변경 후
시뮬레이션을 모두 실행하지 않았다. 이 문서의 수치 중 `입력값`은 소스에서 직접
확인한 확정 데이터이고, 완료율·엔딩·피해량 같은 `플레이 결과`는 측정 보류다.
측정하지 않은 값을 0이나 추정 결과로 대체하지 않는다.

결정 근거는 다음 순서로 적용했다.

1. 최신 [시스템 기획 3차](https://docs.google.com/document/d/1qq1jIdDYxPpKDOucQaEO8RHK7XQDD-ARnDFoeaCtmhQ/edit?usp=drivesdk)
2. [10차 회의록](https://docs.google.com/document/d/1WKZvDG3kVoTKfAEDpLmkqAfMRIIgAF3SVwrAoWdiNCM/edit?usp=drivesdk)
3. [9차 회의록](https://docs.google.com/document/d/1mCbisCxqAHMPckd3CPQleobPSnTv37tf8wsfTNDPP24/edit?usp=drivesdk)
4. [8차 회의록](https://docs.google.com/document/d/1lvPBYfO9X3kqvYXjxZkkKxHj6dlguT3qhvm0mTC9WnA/edit?usp=drivesdk)
5. 정확한 값이 없는 경우 아래에 명시한 보수적 가정

## 동결한 핵심 불변식

| 항목 | 유지값 |
| --- | ---: |
| 맵 | 9×8 |
| 층 | 2개 |
| 최대 턴 | 12 |
| 층 전환 | 6턴 종료 후 |
| 플레이어 최대 HP | 100 |
| 로라 최대 HP | 100 |
| 기본 이동력 | 4 |
| 스타터 | 활과 화살 / 인형탈 |

벽, 아이템, 몹, 순간이동의 ID와 좌표는 바꾸지 않았다. 난이도는 플레이 상태에
따른 숨은 보정이 아니라 `첫 층은 기존 학습 배치`, `지하는 혼합 이벤트와 몹 3개`
라는 데이터 규칙으로만 달라진다.

## 변경 전 입력 지표와 가설

10턴 기준선은 실행 보류 상태이므로 다음 표가 이번 튜닝의 재현 가능한 변경 전
지표다.

| 대상 | 변경 전 입력값 | 문제 가설 |
| --- | ---: | --- |
| 회복 | 행동당 HP +20 | 공격받은 뒤 회복 반복의 기회비용이 작다. |
| 인형탈 방어 | 피해 -10 | 몹과 로라를 동시에 상대할 때 안전 여유가 크다. |
| 인형탈 안정 | 플레이어 턴마다 불안정 -5 | 별도 경로 선택 없이 누적 안정도가 지나치게 크다. |
| 낡은 곰인형 사용 | 불안정 -30 | 한 번의 사용만으로 70에서 40까지 내려 특수 엔딩 구간에 진입한다. |
| 오르골 | 평화 2턴, 평화 중 턴마다 -20 | 공격 2회 차단과 최대 -40 안정이 한 아이템에 겹친다. |
| 기억 사진 | 현재 불안정 ×0.5 | 70에서 35가 되어 단독으로 특수 엔딩 구간에 진입한다. |
| 지하 이벤트 | 안정 -10 타일 4개 | 후반층의 모든 이벤트가 보상이어서 3몹 배치의 압박을 상쇄한다. |
| 활 | 원거리 30, 턴 시작 +3, 로라 피해 +5 | 명확한 공격 보상과 위험이 이미 함께 있어 우선 유지가 필요하다. |

가설은 9차 회의의 `회복량 감소`, `불안정도가 너무 쉽게 내려감`, `현재 난도가
쉬움` 피드백과 8차 회의의 `초반은 쉽고 후반은 어렵게` 방향을 반영한다.

## 변경 후 입력 지표

| 대상 | 변경 후 입력값 | 정적 변화 | 기대 효과 |
| --- | ---: | ---: | --- |
| 회복 | HP +15 | 회복량 -25% | 회복 반복보다 이동·공격·아이템 선택의 가치가 커진다. |
| 인형탈 방어 | 피해 -8 | 감소량 -20% | 방어 정체성은 유지하되 피격을 무시할 수 없게 한다. |
| 인형탈 안정 | 턴마다 -3 | 감소량 -40% | 안정 경로와 아이템을 함께 선택해야 한다. |
| 낡은 곰인형 사용 | 불안정 -20 | 감소량 약 -33% | 70에서 50으로 내려가지만 혼자 엔딩 구간을 만들지 않는다. |
| 오르골 | 평화 1턴, 턴마다 -10 | 차단 -50%, 최대 안정 -75% | 위기 한 번을 넘기는 도구로 역할을 좁힌다. |
| 기억 사진 | 현재 불안정 ×0.7 | 제거 비율 50%→30% | 70에서 49가 되어 추가 안정 선택이 필요하다. |
| 지하 이벤트 | 안정 2 / 피해 1 / 불안정 증가 1 | 보상 4→2, 위험 0→2 | 같은 좌표에서도 후반 경로 선택에 비용이 생긴다. |
| 활 | 변경 없음 | 0 | 공격 스타터의 보상·위험 정체성을 보존한다. |

지하의 `b1-event-4-a`, `b1-event-4-b`는 안정 타일로 유지했다.
`b1-event-4-c`는 피해, `b1-event-4-d`는 불안정 증가로 바꿨다. ID와 좌표를
유지하므로 저장 참조와 맵 형태는 그대로이며, 기존 이벤트 타일 표현이 위험을
사전에 보여 준다. 스타터·아이템 설명도 새 역할과 일치하도록 갱신했다.

테스트 재개 시 먼저 이전 커밋에서 같은 결정론 하네스를 실행해 변경 전 JSON을

늘었는지를 완료로 판정하지 않는다.

## 버섯 지속 규칙 결정

8차 회의록에는 버섯 효과를 `플레이어가 두 번 공격할 때까지` 유지하자는 제안이
있다. 그러나 더 최신인 시스템 기획 3차는 `다음 피해를 입기 전까지 지속`이라고
명시한다. 최신 문서와 충돌하므로 두 번 공격 규칙을 임의로 채택하지 않았다.

현행 규칙은 다음과 같다.

- 사용하면 이동력과 플레이어 공격 피해가 2배가 된다.
- 회복, 대기, 층 전환만으로 종료되지 않는다.
- 플레이어가 양수 피해를 한 번 받으면 종료된다.
- snapshot/checkpoint에는 `mushroomActive`가, 피해 preview에는 종료 예상이
  노출된다.

공격 횟수 규칙을 채택하지 않았으므로 남은 공격 횟수 필드나 저장 스키마를
추가하지 않았다.

## 명시적 가정과 남은 위험

- 회의록에는 감소 방향만 있고 정확한 수치가 없어 15, 8, 3, 20, 1, 10, 0.7은
  기존 값에서 한 단계만 낮추는 보수적 값으로 정했다.
- 지하 위험 타일의 정확한 좌표 지시는 없어 기존 네 좌표 중 아래쪽 두 좌표를
  위험으로 바꿨다. 맵 형태와 참조 ID 보존을 우선했다.
- 오카리나의 불안정 증가 완전 억제는 이번 범위에서 유지했다. 실제 시뮬레이션에서
  항상 최우선 선택으로 드러나면 다음 튜닝 후보가 된다.
- 활 수치는 인형탈 하향과 후반 위험 배치를 먼저 관찰하기 위해 유지했다. 두
  스타터의 완료율 차이는 아직 확인되지 않았다.
- UI 플레이, 연출, 실제 사용자 탐색 행동은 결정론 하네스로도 측정되지 않는다.

## 검증 상태

변경값과 불변식을 고정하는 회귀 테스트 소스는 함께 갱신했다. 다만 이번 턴에는
요청에 따라 `npm test`, 밸런스 시뮬레이션, NW.js 실행, 별도 구문 검사를 수행하지
않는다. 따라서 런타임 통과 여부와 플레이 결과 목표는 검증 보류다.
